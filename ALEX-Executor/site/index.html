03 / GOOD TO KNOW

No confusion. Just facts.

Is the iPhone / Android app native?

It's a progressive web app (PWA), installed from your browser. It's not an App Store app, iOS IPA, or Android APK. Some browsers don't support installing PWAs.

Does ALEX execute Roblox scripts in the Roblox Player?

No. This version is a local Lua/Luau editor and script-file organizer. The desktop app has Roblox templates and a copy-to-Studio Test Lab workflow. It does not connect to Roblox Player or bypass Roblox security protections.

Why isn't my desktop download available yet?

Desktop download buttons only activate when GitHub has published the matching prerelease assets. A failed or incomplete build means there is no verified installer to download yet.

Will it work on every version of Windows and Mac?

No universal compatibility is guaranteed. The current desktop targets are Windows x64, macOS Intel x64, and macOS Apple Silicon arm64. System requirements and OS compatibility still need testing.

Is my script uploaded somewhere?

The web editor stores code in your browser's local storage and does not upload your script to a server. You can export a file backup; clearing browser/site data can delete locally saved edits.
